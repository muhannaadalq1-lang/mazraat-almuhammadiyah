# مزرعة المحمدية

موقع حجز يومي لمزرعة المحمدية (قسمان + المزرعة كاملة) مع لوحة تحكم للمالك.

- `index.html` — الموقع ولوحة التحكم (`/#admin`)
- `js/backend.js` — الاتصال بـ Supabase (قاعدة البيانات، الدخول، رفع الصور)
- `media/` — الصور والفيديوهات
- `supabase/schema.sql` — إنشاء الجداول والصلاحيات (يُشغَّل مرة واحدة)
- `supabase/seed.sql` — البيانات الأولية وتعيين المالك (يُشغَّل مرة واحدة)

النشر: Vercel يستضيف المستودع كموقع ثابت بدون خطوة بناء.
